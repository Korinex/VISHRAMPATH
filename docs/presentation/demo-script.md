# Demo script — VishraamPath (5–7 minutes)

**Opening line:**
> "VishraamPath is a volunteer-surveyed footpath evidence concept for Nagpur. This local prototype shows how human-reviewed observations could inform profile-aware route guidance and a municipal repair queue. The demo data are illustrative. This prototype is not an accessibility certification or a guarantee of safe travel."

**Sequence (each step Pass / Fail / Not tested when rehearsed):**

1. Reset the fixture → point at the **DEMO DATA** label.
2. Open the survey + one ~50 m segment — say plainly: length/GPS are demo, not measured.
3. Open one suggestion → make a real **Confirm / Reject / Not sure** decision — "a suggestion is not a finding".
4. Open screening → show **"Not assessed" + rule version** → "screening only, not certification".
5. Route: **walking-stick + Marathi**, then **wheelchair + Hindi** → captions/text visible, works with speech off → "labelled fixture, not a mapped or safe route".
6. Fix-First queue + CSV → evidence reference, advisory priority, costs blank (no source).
7. Repeat comparison → "repeat comparison", NOT "verified repair" (no intervention + re-check).
8. If time allows: disconnect Wi-Fi, repeat 4–7, note anything that breaks.

**Roles:** Shifa opens (line above) → Jeeya runs survey/review/screens → Pratiksha tells the one-survey-two-outputs story + caveats (see pitch-caveats.md) → anyone covers route/queue.
